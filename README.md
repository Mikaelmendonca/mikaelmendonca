## `Analista de Testes` ##

Me chamo Mikael Mendonça tenho 20 anos e atuo como Profissional de Qualidade de Software (QA), com experiência em testes manuais e automatizados. Sou graduando em Análise e Desenvolvimento de Sistemas e trabalho em todo o ciclo de qualidade, desde a análise de requisitos até a automação. Sou movido por aprendizado contínuo, boas práticas e entrega de software com qualidade.
